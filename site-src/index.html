Install npad with apt or dnf

Signed repositories for npad, the lightweight Notepad-style editor. Install once and npad updates with the rest of your system.

  • Debian 12 & 13
  • Ubuntu 22.04+
  • Linux Mint
  • Fedora
  • amd64
  • arm64
  • riscv64
Quickest

Install in one step

Detects apt or dnf, adds the repository and its key, and installs npad.

curl -fsSL @BASE_URL@/install.sh | sudo sh

Add -s -- --repo-only after sh to add the repository without installing. Read the script first if you prefer.

Or set it up yourself

Debian, Ubuntu, Linux Mint

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL @BASE_URL@/npad.asc \
  -o /etc/apt/keyrings/npad.asc
sudo curl -fsSL @BASE_URL@/npad.sources \
  -o /etc/apt/sources.list.d/npad.sources
sudo apt update && sudo apt install npad

Fedora

sudo curl -fsSL @BASE_URL@/npad.repo \
  -o /etc/yum.repos.d/npad.repo
sudo dnf install npad

apt and dnf pick your machine's own architecture: amd64 (x86_64), arm64 (aarch64) or riscv64. riscv64 needs Debian 13, Ubuntu 24.04 or newer.

Signing key

Repository metadata and packages are signed with npad.asc.

Fingerprint @FINGERPRINT@

Remove

Debian family:

sudo rm /etc/apt/sources.list.d/npad.sources \
  /etc/apt/keyrings/npad.asc

Fedora:

sudo rm /etc/yum.repos.d/npad.repo
