npad package repository

Signed apt and dnf repositories for npad, the lightweight Notepad-style editor. Packages are rebuilt from the GitHub releases for amd64 (x86_64), arm64 (aarch64) and riscv64; apt and dnf pick your machine's own. riscv64 needs Debian 13, Ubuntu 24.04 or newer.

Debian, Ubuntu, Linux Mint

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL @BASE_URL@/npad.asc -o /etc/apt/keyrings/npad.asc
sudo curl -fsSL @BASE_URL@/npad.sources -o /etc/apt/sources.list.d/npad.sources
sudo apt update && sudo apt install npad

Fedora

sudo curl -fsSL @BASE_URL@/npad.repo -o /etc/yum.repos.d/npad.repo
sudo dnf install npad

Either, in one step

curl -fsSL @BASE_URL@/install.sh | sudo sh

Pass --repo-only to add the repository without installing. Read the script first if you like.

Signing key

Metadata and packages are signed with npad.asc.
Fingerprint: @FINGERPRINT@

Remove

sudo rm /etc/apt/sources.list.d/npad.sources /etc/apt/keyrings/npad.asc   # Debian family
sudo rm /etc/yum.repos.d/npad.repo                                         # Fedora
